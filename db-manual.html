载体：Markdown 文件库 注册制：已登记（见 F:codexcatalogdatabase-registry-v0.json） 创建日期：2026-08-14

## 用途

收录国内医美自媒体运营素材：短视频文案、朋友圈文案、账号简介、话术、风格基准等。供国内医美/整形领域的自媒体内容创作、拍摄脚本、运营排期取用。

## 主题关系（重要）

骨相审美 = 理念/内容层：先立"骨相审美"的人设与认知（账号简介、开场钩子、金句），建立审美高度

PEEK = 落地业务层：骨相审美文案最终服务于 PEEK（聚醚醚酮）3D 打印骨相填充/轮廓手术推广——审美理念引流，PEEK 技术承接

创作顺序建议：骨相审美文案做开场与主张 → PEEK 材料科普/对比/案例做承接与转化

素材对应：骨相审美见 素材/骨相审美/，PEEK 见 素材/PEEK/（含材料知识/卖点/账号源）

## 条目规范（写库时必须遵守）

每条文案条目 = 1 个 Markdown 文件，或同主题合集文件内的一个编号小节

每条条目必须包含字段：

id：GM--（GM = 国内医美 Guomei）

原文：文案原文（保留原话，不改写）

主题：骨相审美 / 鼻部 / 眼周 / ...

用途：短视频开场 / 短视频收尾 / 朋友圈 / 简介 / 金句 ...

时长（短视频类）：15s / 30s / 60s

入库日期

来源：用户提供 / 精编 / 生成

用户提供的原文必须原样归档到 raw/，然后才在 素材/ 中整理

风格基准见 素材/风格基准/，新文案应遵守

## 与医美语料库的关系

本库 = 运营/创作素材库（文案、话术、脚本）

F:codexdatamedical-aesthetic-corpus = 行业知识语料库（文章、手术、风险、产品）

两者互补：创作文案时先查本库找表达，需要医学事实/合规依据时查语料库
